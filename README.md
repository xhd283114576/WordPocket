# WordPocket

一个轻量、开源、隐私友好的英文单词记录 PWA。打开网页即可记录单词、中文释义、例句和标签，并用随机卡片快速复习。

## 功能

- 快速记录英文单词、释义、例句和标签
- 搜索并按“学习中 / 已掌握”筛选
- 英文朗读与随机复习
- JSON 数据导入、导出
- 响应式设计，支持手机和桌面
- 可安装为 PWA，支持离线访问
- 数据仅保存在浏览器本地，不上传服务器

## 本地运行

项目没有第三方依赖。因为 Service Worker 需要 HTTP 环境，请用任意静态服务器运行：

```bash
npx serve dist
```

然后打开终端显示的本地地址。也可以直接打开 `dist/index.html`，除离线缓存外的功能均可使用。

## 数据说明

词库保存在浏览器 `localStorage` 中。清除浏览器数据前，请使用页面右上角的“导出”功能备份词库。
